# Project Instructions

## Project Snapshot

**Purpose:** Public CVE intelligence console (wordmark Kevelry; package/image cve-change-radar), with explainable prioritization, searchable descriptions, Change Radar, and a versioned read-only API.
**Stack:** Next.js 16 App Router, React 19, TypeScript, SQLite/FTS5, visx SVG primitives, one Docker image and container.
**Release:** 4.1.1 is the newest published image (`kelanach/kevelry`) — tagged 2026-11-28, `latest` resolves to it; it is the metadata-haystack fix — the number check scanned only `outcome.data`, so an answer quoting a tool's own `retrievedAt` (a date the model had legitimately read) was reported as a fabricated figure; the haystack now includes the metadata an answer may cite, from an explicit 15-key list (`retrievedAt`, `generatedAt`, `computedAt`, `fetchedAt`, `asOf`, `asOfDate`, `version`, `modelVersion`, `catalogVersion`, `datasetVersion`, `kevVersion`, `window`, `dateRange`, `windowStart`, `windowEnd`), with a fabricated figure still flagged, and the accepted trade-off is recorded — a date equal to today verifies, because a false accusation is worse; no migration, no config change. From 4.1.0, the batch-and-numbers release — `get_cves` reads one to ten ids in one call (measured on the fake transport: five single lookups need 6 rounds against the 4-round cap, so the turn silently read 3 of 5 records and answered from those, while one batch call reads 5 of 5 in a single round; ids the dataset does not hold come back in `missing` and are never cited as read); numbers are verified against tool results the way ids already were — percentages, decimals of three or more fractional digits, integers ≥1000 and ISO dates, where a payload's `0.99999` verifies `99.999%` but not `99.2%`, ordinals, small counts and bare years are ignored, and a turn that read nothing accuses nothing — and an unverified figure appears as a quiet caution and in the brief without the answer being edited; citations, number checks and web sources now live in one pure evidence module (`src/lib/ai/evidence.ts`), which dropped the turn module from 819 to 696 lines with no behaviour change (zero existing tests edited); no migration, no API change, no config change. ## Session Protocol (Summary)

1. Confirm context: `CLAUDE.md` and its four imports appear in `/context` under Memory files. Read `.claude/HOW_TO_RESUME.md` for the full protocol.
2. Read `.claude/state/TASK_QUEUE.md`; pick the next unblocked task.
3. Identify the active environment (`APP_ENV`) before running anything. Unknown means production-safety rules apply.
4. Check git state: branch, uncommitted changes, recent commits. Never clobber existing work.
5. Read task-relevant docs, verify the environment, and run the baseline test suite.
6. State a short plan (goal, files, risks, verification) for any non-trivial task.
7. Implement using the matching template in `.claude/templates/`.
8. Verify: tests, lint, type checks, and the Security Gate.
9. Wrap up: one batched write updating state and standards (`/wrap-up`).
